# Linux Permissions

## View Permissions

```bash
ls -l
```

Shows file and folder permissions.

---

## Change Permissions

```bash
chmod +x script.sh
```

Makes a file executable.

---

## Change File Owner

```bash
sudo chown user:user file.txt
```

Changes ownership of a file.

---

## Switch User

```bash
su username
```

Switches to another user account.

---

## Run As Administrator

```bash
sudo command
```

Runs a command with elevated privileges.
