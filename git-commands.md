# Git Commands

## Initialize Git

```bash
git init
```

Starts Git tracking in a folder.

---

## Check Status

```bash
git status
```

Shows changed files and Git status.

---

## Add Files

```bash
git add .
```

Stages all files for commit.

---

## Commit Changes

```bash
git commit -m "message"
```

Creates a save point/version.

---

## Upload To GitHub

```bash
git push
```

Uploads commits to GitHub.

---

## Download Updates

```bash
git pull
```

Downloads updates from GitHub.
