# Linux File Management Commands

## Show Current Directory

```bash
pwd
```

Displays your current directory location.

---

## List Files

```bash
ls
```

Shows files and folders in the current directory.

---

## Change Directory

```bash
cd Downloads
```

Moves into another directory.

---

## Create A Folder

```bash
mkdir test-folder
```

Creates a new folder.

---

## Create A File

```bash
touch notes.txt
```

Creates a new empty file.

---

## Remove A File

```bash
rm notes.txt
```

Deletes a file.

---

## Remove A Folder

```bash
rm -r test-folder
```

Deletes a folder and its contents.
