# Linux Networking Commands

## Show IP Address

```bash
ip a
```

Shows your network interfaces and IP addresses.

---

## Ping A Website

```bash
ping google.com
```

Tests internet/network connectivity.

---

## Show Open Ports

```bash
ss -tulnp
```

Shows listening ports and services.

---

## Show DNS Information

```bash
cat /etc/resolv.conf
```

Displays DNS server configuration.
